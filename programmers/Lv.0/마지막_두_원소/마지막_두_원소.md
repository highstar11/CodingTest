## 1. 문제 설명
정수 리스트 num_list가 주어질 때, 마지막 원소가 그전 원소보다 크면 마지막 원소에서 그전 원소를 뺀 값을 마지막 원소가 그전 원소보다 크지 않다면 마지막 원소를 두 배한 값을 추가하여 return하도록 solution 함수를 완성해주세요.

---

## 2. 설계 과정

단순한 배열의 마지막 값과 그 앞의 값의 비교이므로 아주 단순하게 접근했다. 자바스크립트는 배열의 사용이 자유로운 편이어서 쉽게 배열을 복사하고 마지막에 값을 할당하는 것이 문제가 없었다.
java와는 다르게 배열은 각각 다른 타입의 원소를 갖을 수 있으며, push/filter/reduce와 같은 메소드를 이용해서 쉽게 다룰 수 있다.


## 3. 정답 코드

```javascript
function solution(num_list) {
    let answer = num_list;
    
    if (num_list[num_list.length - 1] > num_list[num_list.length - 2]) {
        answer.push(num_list[num_list.length - 1] - num_list[num_list.length - 2]);
    } else {
        answer.push(num_list[num_list.length - 1] * 2);
    }
    return answer;
}
```

## 4. 코드 설명

단순하게 매개변수로 받은 배열의 마지막 값과 그 앞의 값을 비교하는 로직을 통해 조건 분기를 처리하고 그 내부에서 조건에 만족하는 계산을 진행한다. 배열의 복사 방식에서 다시 생각해봐야 할 부분이 있을 것 같다.
지금과 같은 방식은 배열의 복사가 이루어지는 것이 아니라 같은 배열을 참조하기 때문이다. 변수는 두 개지만 배열의 값은 하나로 동작한다.

## 5. 개선된 코드
```javascript
function solution(num_list) {
    if (num_list[num_list.length - 1] > num_list[num_list.length - 2]) {
        num_list.push(num_list[num_list.length - 1] - num_list[num_list.length - 2]);
    } else {
        num_list.push(num_list[num_list.length - 1] * 2);
    }
    return num_list;
}
```
배열을 복사하거나 참조를 하는 과정을 생략했고, 매개변수로 전달받은 num_list 배열에 값을 추가하고 반환하도록 설정했다.

## 4. 시간 복잡도 분석

만약 처음 작성한 코드에서 참조가 아닌 배열의 복사(let answer = [...num_list])로 계산을 한다면, 시간 복잡도는 선형 시간을 따를 것이다. 배열의 길이를 n이라고 가정했을 때 배열의 길이에 따라 복사를 하는 작업이 n개의 요소를 복사해야 하기 때문이다.
근데 지금과 같이 개선된 코드에서는 배열의 복사가 이루어지지 않고 조건문을 통해 값을 추가하고 반환한다면 상수 시간을 따라 O(n)이 될 것이다.

## 5. 정리

자바스크립트에서 배열은 사실 상 겉모습만 배열이다. 자세히 들여다보면 배열이 아닌 객체 기반으로 이루어진 특수한 구조이다. 자료구조에서 말하는 배열은 메모리에서 나열된 데이터의 집합인데, 자바스크립트의 배열은 length 프로퍼티를 갖는 객체인 것이다. 그렇기 때문에 메모리 할당이나 타입을 신경쓰지 않고 리스트처럼 사용이 가능한 것이다.
이런 부분들을 면접에서 물어본다면 나는 자료구조에서의 배열에 대한 설명을 나열했을 것이다. 비록 해당 문제는 Lv.0이지만, 자바스크립트 배열에 대한 이해와 복사에 대한 이해를 다시 한 번 기억시켜주는 문제였다.
