## 구현 요구사항
양의 정수 n이 매개변수로 주어질 때, n이 홀수라면 n 이하의 홀수인 모든 양의 정수의 합을 return 하고 n이 짝수라면 n 이하의 짝수인 모든 양의 정수의 제곱의 합을 return 하는 solution 함수를 작성해 주세요.

## 초반 설계(러프하게)
n -> 6이라고 했을 때, 길이가 n인 배열을 만든다?
그럼 [ un, un, un, un, un, un ] -> 1~6까지 값 할당하고 짝수 번째만 제곱해서 reduce?
비효율적인 거 같기도 하다. 애초에 배열을 만들 때 짝수이면 절반 홀수이면 절반 + 1(자기자신)

7 -> 1,3,5,7
6 -> 2,4,6

길이로 만들면 될듯. 그럼 배열은 어떻게 만드냐? -> new Array 생성자를 이용해서 길이를 할당하고 배열을 생성하자.

```
let obj;
let total = 0;

if(짝수) {
	obj = new Array(Math.trunc(n/2));
	n 이하의 짝수 / n = 6 -> 2, 4, 6
	
	for (let i = 1; i <= n; i++) {
		if (i % 2 === 0) obj.push(i * i);;
	}
	total = obj.reduce((value, sum) => value + sum, 0)
	obj = new Array(Math.trunc(n/2 + 1));
}
```

이렇게 하면 배열에 push 되지 않을까?

## 실행 결과
당연히 오류가 발생한다. -> new Array 생성자로 배열을 만들면 이미 undefined로 각 인덱스의 값이 할당되었기 때문에 push를 하면 이미 선언한 배열의 길이보다 하나 위에 추가한다.
즉, new Array(4)로 선언하고 push로 값을 할당하면 [ ... , 4 ] 가 되어버려서 길이가 5인 배열이 되는 것이다.

## 초기 정답 코드

```
function solution(n) {
    let obj = [];
    let total = 0;

    if(n % 2 === 0) {
        for(let i = 1; i <= n; i++) {
            if(i % 2 === 0) {
                obj.push(i * i);
            }
        }
        total = obj.reduce((value, sum) => value + sum, 0);
    } else {
        for(let i = 1; i <= n; i++) {
            if(i % 2 !== 0) {
                obj.push(i);
            }
        }
        total = obj.reduce((value, sum) => value + sum, 0);
    }
    
    return total;
}
```
obj 배열을 빈 배열로 생성하고 길이를 할당하지 않고 if문을 한 번 더 사용해서 짝수/홀수의 경우에 대해서 값을 push하였다. 그리고 최종적으로 만들어진 obj 배열을 reduce 메소드를 통해 모두 더한 값을 반환한다.
코드는 정답이 나왔지만, 구조적으로 너무 복잡하고 reduce, push와 같은 불필요한 연산을 줄이고 싶었다.

## 최종 코드
```
function solution(n) {
    let total = 0;
    
    if(n % 2 === 0) {
        for(let i = 2; i <= n; i = i+2) {
            total += i * i;
        }
    } else {
        for(let i = 1; i <= n; i = i+2) {
           total += i;
        }
    }
    return total;
}
```
최종적으로는 불필요한 메모리 사용을 줄였고, 반복 횟수를 줄였다. 기존에 push()로 값을 배열에 저장하는 것과 reduce()로 값을 합산하는 과정을 없애면서 공간 복잡도를 개선했고 계산 방식을 더욱 효율적으로 바꿨다.
또한, 내부에서 조건문을 다시 사용하는 로직을 없애서 코드의 구조를 단순화시켰다.
