# 💻 Coding Test Archive

> 문제를 푸는 것에서 끝나지 않고, 풀이 과정을 이해하고 더 나은 해결 방법을 고민합니다.

코딩테스트를 오랫동안 하지 않아서 굳은 머리를 깨우기 위한 레벨 0부터의 학습 과정을 담습니다.

프로그래머스, LeetCode, 백준 등 다양한 플랫폼의 코딩 테스트 문제를 JavaScript/Java로 풀이하고 기록하는 저장소입니다.
단순히 정답 코드를 저장하는 것을 넘어, **문제 설계/핵심 알고리즘/시간 복잡도/개선 과정**을 함께 정리합니다.

## 📂 Repository Structure

```text
coding-test/
├── README.md
│
├── programmers/
│   |
│   ├── Lv.0/
│   │   └── problem-name/
│   │       ├── solution.js
│   │       └── solution.md
│   ├── Lv.1/
│   └── Lv.2/
│
├── leetcode/
│
└── baekjoon/
```

각 문제는 독립된 디렉토리로 관리하며, 문제별로 **풀이 코드와 해설 문서**를 함께 작성합니다.

- `solution.js` : JavaScript 풀이 코드
- `solution.md` : 문제 요약, 접근 방법, 풀이 과정, 복잡도 분석 및 회고

플랫폼별 문제 수가 늘어나도 쉽게 탐색할 수 있도록 디렉터리를 구성합니다.

## 📝 Solution Guide

모든 문제는 다음 기준에 따라 기록합니다.

| 항목 | 기록 내용 |
|:--|:--|
| Problem | 문제 링크 및 핵심 요구사항 |
| Approach | 문제 해결을 위한 사고 과정 |
| Algorithm | 사용한 자료구조 및 알고리즘 |
| Complexity | 시간 복잡도와 공간 복잡도 |
| Review | 어려웠던 점, 개선점, 새롭게 배운 내용 |

정답을 맞히는 것으로 멈추지 않고, **왜 이 방법을 선택했는지 설명할 수 있는 풀이**를 목표로 합니다.
